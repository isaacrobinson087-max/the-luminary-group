# The Luminary Group

Luxury talent management website frontend preview.

## Run
Open `index.html` in a browser or serve the folder with any static file server.

## Included
Responsive homepage, animated orbital hero, demo talent directory and filters, services, booking enquiry demo, and admin preview.

## Important
All talent names are fictional demonstration data. Booking enquiries are **not** sent or stored. No backend, Firebase, Supabase, payments, or hosting is configured.
